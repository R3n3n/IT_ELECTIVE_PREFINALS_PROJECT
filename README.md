# EF Core Database Project

## Project Information

### Project Name
EF_Core_Database 

---

### .NET Version
.NET 8

---

### Entity Framework Core Version
Entity Framework Core 8.0.13

---

### NuGet Packages
- Microsoft.EntityFrameworkCore
- Microsoft.EntityFrameworkCore.Sqlite

---

### Database
SQLite  

---

### Database Location
- Located in the project root: "lycevm.db"
- The connection string is configured in "appsettings.json"

---

### How to Run
1. Clone the Repository.
2. Open the project in Visual Studio.
3. Restore the NuGet Packages.
4. Ensure lyceum.db is present in the project root.
5. Build the Solution.
6. Run the Application using Visual Studio.
7. Open the URL that is displayed in the terminal or browser.
